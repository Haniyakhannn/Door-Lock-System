Working Principle
The system operates using a 4-digit password.When the user enters the password through the keypad:
•	If the entered password matches the stored password:
o	The buzzer beeps once
o	The servo motor rotates to unlock the door latch
o	LCD displays "Correct Password" and "Door Opened" or "Door Locked" depending on action
•	If the password is incorrect
o	The user can try 2 more times and if the password after the 3rd try is still incorrect then the buzzer beeps for a minute and work as a alarm system.
o	The servo motor stays locked
o	LCD displays "Wrong Password" and "Please Try Again"
A latch mechanism connected by a steel rod with the servo enables mechanical movement. All user interactions and system states are shown on the LCD screen.
